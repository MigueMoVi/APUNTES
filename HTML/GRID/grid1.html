1. Grid-template-[]

grid-template-columns: [] [] [] []... ;
grid-template-rows : [] [] [] []... ;

Por ejemplo, deseamos poner tres columnas, la primera de 200px, la segunda de 100px, y la tercera de 200px: 

			.grid-container{

				display: grid;
				grid-template-columns: 200px 100px 200px;

3. FRACCIONES Y TAMAÑOS

La unidad fr en CSS es una unidad de medida flexible y fraccionaria diseñada exclusivamente para el sistema de CSS Grid Layout que representa una parte del espacio disponible.
¿Qué es y cómo funciona?

  • Fracción de espacio: 1fr equivale a una fracción (o parte) del espacio total libre que hay dentro del contenedor de la cuadrícula.
  • Repartición proporcional: Si defines grid-template-columns: 1fr 2fr;, el espacio libre se divide en 3 partes; la primera columna toma 1 parte (33.3%) y la segunda toma 2 partes (66.6%).
  • Cálculo automático de los espacios (gaps): A diferencia de los porcentajes (%), la unidad fr resta de manera automática el espacio ocupado por los huecos (gap) antes de repartir el espacio restante, evitando que tu diseño se desborde.
  • Conveniente para un diseño responsivo

Por ejemplo

			.grid-container3{
				border: solid 2px #f5b638;
				padding: 2px;
				display: grid;
				grid-template-columns: 1fr 1fr 1fr; 
				gap: 1em
			}

4. VIEW PORTS (vm)

Corresponden al 1% de la dimensión más pequeña de la ventana gráfica (viewport), ya sea su ancho o su alto

Qué son las unidades de Viewport

  1. vw (Viewport Width): Equivale al 1% del ancho total de la pantalla o ventana del navegador.
  2. vh (Viewport Height): Equivale al 1% de la altura total de la pantalla o ventana del navegador.
  3. vmin (anteriormente llamada vm): Toma el valor menor entre vw y vh. Si el dispositivo está en vertical, representa el ancho; si está en horizontal, representa el alto.
  4. vmax: Toma el valor mayor entre vw y vh
Sirven para:

No confundir con:
• 100% (Porcentaje): Depende del contenedor padre. Si el padre mide solo 300px, el elemento medirá 300px.
• 100vw / 100vh (Viewport): Depende de la pantalla. No le importa cuánto mida el padre; se estirará para ocupar toda la ventana del navegador.

  • Diseño responsivo: Permiten escalar textos o elementos de forma fluida sin depender de contenedores padres ni de media queries complejas.
  • Tipografía adaptable: Se usan para definir tamaños de fuente (font-size) que se ajusten automáticamente al tamaño de cualquier pantalla

Note que con esto se puede establecer que un elemento o contenedor puede ocupar un porcentaje CON RESPECTO A LA PANTALLA.


5. ALINEAR OBJETOS

Observe el siguiente diseño:

	.grid-container4{
		border: solid 2px #f5b638;
		padding: 2px;
		display: grid;
		grid-template-columns: 100px 100px 100px; 
		grid-template-rows: 100px 100px 100px; 
		gap: 1em
	}


	.item4{
		border: solid 1px blue;
		padding: 0.01em;
		text-align: center;
		width: 50px;
		height: 50px;
	}

El contenedor tiene celdas de 100px de alto y 100 px de largo, además hay un espacio entre estas celdas definido por gap: 1em
Los cuadrados (item4) tienen un tamaño fijo en pixeles de 50px de alto y 50px de largo, lo que significa que no ocupan todo el espacio disponible que les ofrece su contenedor padre.
Ahora todos los cuadrados están alineados a la izquierda por defecto.

Para controlar el posicionamiento de los objetos dentro de estos espacios podemos usar lo siquiente:

- justify-items : Alinear horizontalmente
- align-items : Alinear verticalmente

Para controlar el posicionamiento del objeto respecto a su contenedor (por ejemplo centrar en la pantalla):

- justify-content : Alinear horizontalmente
- align-content : Alinear verticalmente

Ambas configuraciones pueden tomar uno de los 3 parámetros:

  • start : izquierda
  • center: dentro
  • end: derecha
Por ejemplo tenemos lo siguiente; 
	.grid-container4{
		border: solid 2px #f5b638;
		padding: 2px;
		display: grid;
		grid-template-columns: 100px 100px 100px; 
		grid-template-rows: 100px 100px 100px; 
		gap: 1em
	}
	
	.item4{
		border: solid 1px blue;
		padding: 0.01em;
		text-align: center;
		width: 50px;
		height: 50px;
	}
