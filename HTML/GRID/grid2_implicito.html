GRID implícito

¿Qué sucede si no sabemos con exactitud cuantos datos van a haber dentro de un contenedor pero debemos de acomodarlos bien para el usuario? Por ejemplo, si recibimos información de una base de datos no sabemos con certeza cuantos son y la cantidad puede variar cada vez.

Tenemos que preparar la configuración para que esta sea automática y todos los datos futuros de muestren correctamente.

.grid-container2{
	border: solid 2px #f5b638;
	display: grid;
	grid-template-columns: 50px 50px 50px; /*aca*/
	grid-auto-rows: 50px;
	height: 80px;
	width: 200px;
}

Observe que en el primer ejemplo se ha puesto 14 cajas para tratar de acomodarlas en un espacio definido de dimensiones height: 80px; width: 200px;. Por este motivo las cajas se desbordan por debajo.

En el primer ejemplo, solo se define el alto SOLO DE LAS DOS PRIMERAS FILAS de 50px, pero cuando llega la tercera fila el formato de 50px se pierde, juntanto todas las cajas arruinando la presentación visual. Por eso se usa grid-auto-rows: 50px; que define un alto fijo para todas las filas necesarias sin importar su cantidad, establecida en 50px. De esta forma no se pierde el formato sin importar cuantos datos ingresarán en nuestro contenedor.

Las cajas no tienen ancho ni alto establecido, además y el contenedor ... Note que ya no es necesario especificar el tamaño de caad columna, sino que se asigna automáticamente con grid-auto-columns. Tambien se usó 

.grid-container3{
	border: solid 2px #f5b638;
	display: grid;
	
	grid-auto-columns: 40px; /*aca*/
	grid-auto-flow: column;
	grid-auto-rows: 50px;
	
	height: 80px;
	width: 200px;	
}

Esta configuración puede ser útil cuando se necesitan mostrar varios elementos (no sabemos cuantos) en una fila. Por ejemplo, el catálogo de series de Netflix.
