    Query Selector

    Devuelve una referencia objeto apuntando directamente al nodo que está guardado en la memoria del navegador (en el arbol del DOM).


    Añadir elementos

    Primero creamos un "puntero" haciendo un query para buscar la lista u objeto al que queremos añadir algo. Por ejemplo a la lista donde se insertan las tareas hechas

     const lista = document.querySelector('#lista');

    Luego podemos agregar el resultado de varias maneras:

    • Esto va a insertar el texto como tal dentro de la lista 
      • lista.append('<li> holaa </li>')
    • En cambio, ahora se está creando un elemento html antes y luego se pasa ese elemento 
      • const li = document.createElement('li');
li.textContent = "Nuevo elemento de la lista"

// AGREGAR EL HTML EN "li"
lista.append(li);
    • Usando innerHTML que interpreta código html 
      • const L = document.querySelector('#lista');
const E = "hola"
L.append(E);

    Obtener valores del html usando funciones

    Podemos obtener los valores de los elementos de la lista con: 

    		const EEE = document.querySelectorAll(".texto"); 
    		EEE.forEach(e => { console.log(e.textContent); });

    Y el resultado es la impresión una tras otra de los elementos guardos. Note que

    También podemos hacer lo siguiente:

    		const N = document.getElementsByClassName("texto"); 
    		for (let i = 0; i < N.length; i++) {
			console.log(N[i].textContent); 
		}

    Note la diferencia cuando se usa querySelectorAll a diferencia de getElementsByClassName

    • querySelectorAll(".texto") -> Devuelve una NodeList
      • Tiene el método .forEach() implementado de forma nativa.
      • Puede contener no solo elementos HTML, sino también nodos de texto o comentarios (aunque con selectores CSS como .texto solo trae elementos).
    • getElementsByClassName("texto") -> Devuelve una HTMLCollection
      • No tiene .forEach(), por lo que necesitas un bucle for, for...of, o convertirla con Array.from()
      • Solo contiene elementos HTML.
