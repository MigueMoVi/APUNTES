Aceptar entradas de usuario

Aceptar la entrada de un usuario

Podemos hacerlo mediante dos formas

1. Window prompt - EASY

Esto se hace usando javascript con la función: window.prompt("...") para asignar el valor recibido a una variable. Esto fue la ventana que se ha visto al incio

		let Nombre
		Nombre = window.prompt("¿Cuál es tu nombre? ")
		// Imprimir en consola
		console.log(Nombre);

2. HTML Text box - PROFESSIONAL

Vamos a usar < input>, < label> y que tenga un botón que llame a una función de JS que lea el contenido del input

		< label>Nombre:< /label>
		< input id = "nombre_input">< br>
		< button id = "mySubmit"> Enviar nombre < /button> 
		let nombre;
		document.getElementById("mySubmit").onclick = function(){
			nombre = document.getElementById("nombre_input").value;
			console.log(nombre);
		}


Este es un ejemplo de una función anónima. No tiene nombre y se suele usar cuando se necesita realizar una función rápida que solo será usada una vez en toda la ejecución, y no serviría mucho hacer un definición completa. Solo se usa una vez
