Uso de fetch básico

La API Fetch proporciona una interfaz JavaScript para acceder y manipular partes del canal HTTP, tales como peticiones y respuestas. También provee un método global fetch() que proporciona una forma fácil y lógica de obtener recursos de forma asíncrona por la red.

RETORNA UNA PROMESA 

fetch('http://example.com/movies.json')
	.then(response => response.json())
	.then(data => console.log(data));

Por ejemplo, si tenemos un archivo JSON donde se guarda la relacion de personas en formato JSON podemos acceder a esta información si conocemos la ruta...
El contenido del archivo "person_Spongebob.json" es: 

{
	"name": "Spongebob",
	"age": 30,
	"isEmployed": true,
	"hobbies": ["Jellyfishing", "Karate"]
}

Entonces podemos hacer:

	fetch("person_Spongebob.json")
			.then( response => response.json() )
			.then( value => console.log(value) )
			.catch(error => console.log(error)); 
 >> Object { name: "Spongebob", age: 30, isEmployed: true, hobbies: (2) […] }

OBS: Solo se podrán ver los resultados iniciando un servidor


Ahora tenemos un arreglo de objetos como del ejemplo anterior en un archivo "persons.json"

	fetch("persons.json")
		.then( response => response.json() )
		.then( value => console.log(value) )
		.catch(error => console.log(error)); 
 >>
	Array(5) [ {…}, {…}, {…}, {…}, {…} ]
	0: Object { name: "Spongebob", age: 30, isEmployed: true, … }
	1: Object { name: "Elena Rostova", age: 28, isEmployed: true, … }
	2: Object { name: "Marcus Vance", age: 42, isEmployed: false, … }
	3: Object { name: "Yuki Tanaka", age: 24, isEmployed: true, … }
	4: Object { name: "Carlos Mendoza", age: 35, isEmployed: true, … }
	length: 5
	: Array []

O también podemos imprimir cada elemento por separado

	fetch("persons.json")
		.then( response => response.json() )
		.then( values => values.forEach(value => console.log(value)) )
		.catch( error => console.log(error));
 >>
	Object { name: "Spongebob", age: 30, isEmployed: true, hobbies: (2) […] }
	Object { name: "Elena Rostova", age: 28, isEmployed: true, hobbies: (3) […] }
	Object { name: "Marcus Vance", age: 42, isEmployed: false, hobbies: (2) […] }
	Object { name: "Yuki Tanaka", age: 24, isEmployed: true, hobbies: (3) […] }
	Object { name: "Carlos Mendoza", age: 35, isEmployed: true, hobbies: (3) […] }

Como podemos ver, al obtener los datos de una fuente externa de esta manera estamos obteniendo objetos JSON que podemos usar (value.name, value.age, ...)


Ejemplo 

var miImagen = document.querySelector("img");

var miSolicitud = new Request("flores.jpg");

fetch(miSolicitud)
  .then(function (respuesta) {
    return respuesta.blob();
  })
  .then(function (respuesta) {
    var objeto = URL.createObjectURL(respuesta);
    miImagen.src = objeto;
  });
