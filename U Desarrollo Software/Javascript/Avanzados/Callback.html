Callbacks

Una función de callback es una función que se pasa a otra función como un argumento, que luego se invoca dentro de la función externa para completar algún tipo de rutina o acción.
Se puede usar para:

  • Leer un archivo
  • Solicitudes en red
  • Interactuar con bases de datos

"Hey, cuando termines, llama a esta siguiente función"

Por ejemplo, queremos que se imprima el mensaje de ADIÓS después de decir HOLA: 

hello();
goodbye();
function hello(){
	console.log("hello");
}

function goodbye(){
	console.log("Goodbye");
} 
// Con callback
hello(goodbye); // Se pasa sin () 

function hello(callback){
	console.log("hello");
	callback(); /*Llamada a la función*/ 
}

function goodbye(){
	console.log("Goodbye");
}

Ambos códigos producen la misma salida

Se pueden pasar parámetros como a cualquier otra función para manejar una lógica diferente 

// Función para sumar dos números
sum(displayConsole, 2, 5);

function sum(callback, x, y){
	let result = x + y;
	callback(result);
}

function displayConsole(numero){
	console.log(numero);
}

Otro ejemplo

function saludar(nombre) {
  alert("Hola " + nombre);
}

function procesarEntradaUsuario(callback) {
  var nombre = prompt("Por favor ingresa tu nombre.");
  callback(nombre);
}

procesarEntradaUsuario(saludar);
