Consumir datos de una API: Pokemóm

Recordemos un poco de FETCH...
Es una función usada para hacer solicitudes HTTP para obtener recursos (datos de estilo JSON, imágenes, archivos, etc)
- Simplifica la solcicitud de datos de forma asíncrona
- Usado para interactuar con APIs para enviar y recibir de forma asíncrona en toda la web

fetch(url, {options: GET})

(por defecto)

fetch(url, {options: POST})


Usaremos https://pokeapi.co/ para consumir una API
Comenzamos obteniendo los datos de Pikachu, copiando el link directamente de la opción que ofrece la página:

Respuestas

Vamos a ver qué sucede cuando obtenemos una respuesta de la API

fetch("https://pokeapi.co/api/v2/pokemon/pikachu")
	.then(response => console.log(response))
	.catch(error => console.error(error));
 
Response { type: "cors", url: "https://pokeapi.co/api/v2/pokemon/pikachu", redirected: false, 
status: 200, ok: true, statusText: "", headers: Headers(5), body: ReadableStream, bodyUsed: false }

En la parte de body se encuentran los datos de Pikachu y hemos obtenido UNA RESPUESTA DE 200. Además note también que tenemos la propiedad OK que representa que la respuesta del servidor ha sido exitosa.
Si obtuvimos un respuesta incorrecta o el servidor rechazó la solicitud tendremos:

 
fetch("https://pokeapi.co/api/v2/pokemon/pikachu")
	.then( response => response.json()) // Obtenemos la repuesta pero convertida en JSON
	.then( data => console.log(data) ) // Si se hizo la conversión correctamente, mostrarlo
	.catch( error => console.error(error));

Alternativa: De manera Síncrona

Podemos implementar la misma funcionalidad pero de manera síncrona usando una función: 

 
fetchData();

async function fetchData(){
	// Si hubo respuesta correcta
	try{
		// Constante que tiene el objeto de la respuesta
		const response = await fetch("https://pokeapi.co/api/v2/pokemon/charizard");
		console.log(response.ok);
		
		// Si la respuesta es no es OK (FALLÓ) lanzamos error
		if (!response.ok){
			throw new Error("No se encontró este pokemón");
		}
		
		// Caso contrario, continúa
		// esto retorna una promesa, por eso usamos AWAIT
		const data = await response.json(); 
		
		console.log(data);
	}
	// Si hay errores solo existe un parámetro
	catch(error){
		console.log(error);
	}
	
}

Ejemplo con imágenes

Esta API tambien nos permite obtener imágenes de los pokemones. Tenemos el siguiente input para poder solicitar la imagen:

Código

async function fetchData(){
	// Si hubo respuesta correcta
	try{
		// Obtenemos el valor del input y luego a minúsculas
		const pokemonName = document.getElementById("pokemonName").value.toLowerCase();
		
		// Solicitud
		const response = await fetch(`https://pokeapi.co/api/v2/pokemon/${pokemonName}`);
		
		
		// Si la respuesta es no es OK (FALLÓ) lanzamos error
		if (!response.ok){
			throw new Error("No se encontró este pokemón");
		}
		
		// Caso contrario, continúa
		// esto retorna una promesa, por eso usamos AWAIT
		const data = await response.json(); 
		
		console.log(data);
	}
	// Si hay errores solo existe un parámetro
	catch(error){
		console.log(error);
	}	
} 
async function fetchData(){
	// Si hubo respuesta correcta
	try{
		// Obtenemos el valor del input y luego a minúsculas
		const pokemonName = document.getElementById("pokemonName").value.toLowerCase();
		
		// Solicitud
		const response = await fetch(`https://pokeapi.co/api/v2/pokemon/${pokemonName}`);
		
		
		// Si la respuesta es no es OK (FALLÓ) lanzamos error
		if (!response.ok){
			throw new Error("No se encontró este pokemón");
		}
		
		// Caso contrario, continúa
		// Ahora vamos a obtener (fetch) el atributo front_default (donde está la IMG)
		const data = await response.json();
		const pokemonSprite = data.sprites.front_default;
		
		
		// Ahora modificar la imagen y mostrarla
		const imgElement = document.getElementById("pokemonSprite");
		// Modificar src de la imagen, estaba VACÍA, pero ahora será llenada con:
		imgElement.src = pokemonSprite; // https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/6.png
		imgElement.style.display = "block";
		console.log(pokemonSprite);
	}
	// Si hay errores solo existe un parámetro
	catch(error){
		console.log(error);
	}
}
