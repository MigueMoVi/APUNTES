setTimeout(callback, delay)

El método global setTimeout() establece un temporizador que ejecuta una función o una pieza de código específica una vez que expira el temporizador.
Sintaxis: 

setTimeout(code)
setTimeout(code, delay)

setTimeout(functionRef)
setTimeout(functionRef, delay)
setTimeout(functionRef, delay, param1)
setTimeout(functionRef, delay, param1, param2)
setTimeout(functionRef, delay, param1, param2, /* … ,*/ paramN)
  • functionRef : Una función que se ejecutará después de que expire el temporizador.
  • code: Una sintaxis alternativa que le permite incluir una cadena en lugar de una función, que se compila y ejecuta cuando expira el temporizador. Esta sintaxis no se recomienda por las mismas razones que hacen que el uso de eval() sea un riesgo para la seguridad.
  • delay (Opcional): El tiempo, en milisegundos, que el temporizador debe esperar antes de que se ejecute la función o el código especificado. Si se omite este parámetro, se utiliza un valor de 0, lo que significa ejecutar "inmediatamente", o más exactamente, el siguiente ciclo de eventos.

Por ejemplo, una función que muestra un número después de 3 segundos después de haber sido llamada

Codigo: 
// Generar número aleatorio: Math.random()
const resultado = document.getElementById("resultado_random");
function TimerRandom(){
	setTimeout( () => resultado.textContent = Math.random(), 2000 );
}

clearTimeout(timeoutId)

Puede cancelar un timeout antes de que se termine
Por ejemplo, un contador de 3 segundos que se puede detener: 

let timeoutId;
const texto_cuenta = document.getElementById("cuenta_regresiva");
let cantidad_segs = 3;

// Función de inciar
function startTimer(){
	texto_cuenta.textContent = "";
	// Asignamos a esa variable
	timeoutId = setTimeout( () => texto_cuenta.textContent = "Cuenta regresiva terminada" , cantidad_segs*1000)
}

// Función de terminar
function clearTimer(){
	clearTimeout(timeoutId);
	texto_cuenta.textContent = "Contador detenido";
}

setInterval()

Llama a una función o ejecuta un fragmento de código de forma reiterada, con un retardo de tiempo fijo entre cada llamada.
Sintaxis: 

setInterval(code);
setInterval(code, delay);

setInterval(func);
setInterval(func, delay, arg0);
setInterval(func, delay, arg0, arg1);
setInterval(func, delay, arg0, arg1, /* ..., */ argN);

Ejemplo

var intervalID = setInterval(myCallback, 500, "parámetro 1", "parámetro 2");

function myCallback(a, b) {
  // Tu código debe ir aquí
  // Los parámetros son totalmente opcionales
  console.log(a);
  console.log(b);
}

Se puede hacer un reloj con esta función y actualizar el string cada segundo

: :

Código 

const segundos = document.querySelector("#segundos");
const minutos = document.querySelector("#minutos");
const horas = document.querySelector("#horas");

function UpdateSeconds(){
	// Creamos la fecha actual en cada ejecución para obtener el segundo exacto
	const now = new Date();
	horas.textContent = now.getHours().toString();
	minutos.textContent = now.getMinutes().toString();
	segundos.textContent = now.getSeconds().toString();
	
	//console.log(now.getSeconds().toString());
}
// Actualizar cada segundo
UpdateSeconds();
setInterval(UpdateSeconds, 1000);
