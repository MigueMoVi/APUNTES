Manejo de errores

Cuando un error ocurre se crea un objeto para representar el problema que sucede. Suelen ocurrir en las entradas de usuario o cuando se trata de establecer una conexión.
En esta situación, podemos usar las siguientes sentencias para el manejo correcto del error:

  • try{}: Encierra el código que puede causar un error
  • catch{}: Captura y maneja cualquier error que se haya generado en la sección try
  • finally{}: (OPCIONAL) Siempre se ejecuta. Usado comúnmente para limpiar la ejecución, cerrar conexiones, liberar recursos

Por ejemplo, tratamos de usar el valor de x, que es una variable que nunca ha sido definida. Esto ocasionará un error, pero en vez de detener el programa, vamos a imprimir el error en consola evitando la interrupción y mostrando un mensaje al final 

try{
	console.log(X);
}
catch(error){
	console.log(error);
}
finally{
	console.log("Esta parte siempre se ejecuta")
}

La salida es: 

 >> ReferenceError: X is not defined
 >> Esta parte siempre se ejecuta

Construir errores

Las entradas de usuario siempre son peligrosas para el flujo del programa. Un caso muy práctico y simple para entenderlo, es la división. No se puede dividir por cero, y cuando el usuario trata de hacerlo se generará un error
Por ello, nosotros debemos de validar que esto no suceda:

Errores?:

El código para esta parte es: 

	function Division(){
		// Manejar el error
		let errorS = document.getElementById("errores");
		let inputDividendo = document.getElementById("dividendo");
		let inputDivisor = document.getElementById("divisor");
		try{
			let dividendo = Number(inputDividendo.value);
			let divisor = Number(inputDivisor.value);
			
			
			// Error
			if (divisor == 0){
				// Crear un objeto de tipo error
				throw new Error("No puedes dividir entre 0");
			}
			if (isNaN(dividendo) || isNaN(divisor)){
				throw new Error("Ingrese un número, no letras");
			}
			
			// Si no hubo errores
			let result = dividendo / divisor;
			let res_s = document.getElementById("resultado");
			
			res_s.textContent = `${dividendo} / ${divisor} = ${result}`;
			// limpiar
			errorS.textContent = "NO";
			inputDividendo.value = "";
			inputDivisor.value = "";
		}
		catch(error){
			console.log(error);
			// Mostrar error en la pantalla, parte de Errores?
			errorS.textContent = `SI: ${String(error)}`;
		}
		finally{
			document.getElementById("estado").textContent = "Terminado, siempre se muestra";
		}
	}
