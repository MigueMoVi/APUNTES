Tipos de datos primitivos (7)

Son datos simples e inmutables que no son objetos:

  • string (Cadena de texto): Texto delimitado por comillas, como "Hola".
  • number (Número): Números enteros y decimales (coma flotante), incluyendo valores como Infinity y NaN.
  • bigint (Número entero grande): Enteros de longitud arbitraria para operaciones con números gigantes.
  • boolean (Booleano): Valor lógico que solo puede ser true (verdadero) o false (falso).
  • undefined (Indefinido): Variable declarada a la que no se le ha asignado ningún valor todavía.
  • null (Nulo): Ausencia intencional de cualquier valor o un valor vacío.
  • symbol (Símbolo): Valor único e inmutable usado como identificador de propiedades para evitar colisiones.

Tipos de datos no primitivos (1)

  • object (Objeto): Estructuras de datos complejas para colecciones de valores y entidades más elaboradas. Los arreglos (Array) y las funciones (Function) son variantes especiales de este tipo.

Obtener valores de html - document.getElementById("").textContent

Para obtener los valores de un elemento que está en la página, debemos de conocer el id.

Por ejemplo, si tenemos el siguiente HTMl

	< p class=​"rpta" id=​"nombre">​El nombre es Bro​< /p>​

Y queremos obtener el valor de este nombre

	let texto = document.getElementById("nombre").textContent;
	console.log(texto); // Muestra: "El nombre es Bro"

Probar esto en consola.


Ejemplo

Se rellenarán los espacios con el contenido de variables que están en el archivo .js

		< div id = "ej1">
			< p class = "rpta" id = "nombre">< /p>
			< p class = "rpta" id = "edad">< /p>
			< p class = "rpta" id = "isStudent">< /p>
		< /div>
	
		// ====== Rellenar div de datos ejemplo 1
		let name1 = "Bro";
		let edad = 25;
		let isStudent = true;

		document.getElementById("nombre").textContent = `El nombre es ${name1}`;
		document.getElementById("edad").textContent = "La edad es "+edad;
		document.getElementById("isStudent").textContent = "Es estudiante? " + isStudent;

Note que se usa "document." y esto es porque se está buscando dentro de todo el documento HTML. Probar haciendo lo mismo en la consola del navegador para ver que toda la pantalla se pinta de un color al escribir "document"
