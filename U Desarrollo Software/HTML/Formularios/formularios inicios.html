Inicios formularios

Formularios básicos

Se usa la etiqueta general "form", que contiene a todos los elementos del formulario

Los elementos son los siguientes

  • label: contiene un texto
  • input: almacena texto y no tiene etiqueta final (NO se cierra "< /input >"). Además si no se cambia el tamaño de este elemento se queda con un tamaño establecido (Dependiente de estilos)
OBS: Los botones que están dentro de un formulario recargarán la página automáticamente al hacerles click. Este comportamiento es por defecto

Es buena práctica usar for="fname en los labels con id="fname" en los inputs ambos al mismo tiempo, ya que esto habilita la función para hacer click en el label y resaltar el input del mismo fname o tipo. Pensando en la comodidad del usuario

El atributo name = "name" asigna un nombre a este input para que cuando se envíe datos del formulario con GET o POST se envie como clave-valor usando este nombre asignado. El problema de usar id es que, como bien sabemos es un identificador para agregar estilos, y por ejemplo este input usa id = "name2" y si agregamos algún estilo se verá afectado


Tipos de input

Existe un tipo especial de input usando el atributo type = "reset" que MUESTRA UN BOTÓN que elimina el contenido de todo el contenido de todos los inputs del formulario al que pertenece


El type = "submit" que sirve para enviar datos y también se comporta como un botón. Se cambia el nombre con value="nombre" porque tiene un valor por defecto

 Esta funcionalidad de usa agregando una acción al formulario para hacer un GET por ejemplo y usar el name que habíamos visto hace un rato y mandarlo a la URL (Muy inseguro en la aplicación de páginas)

El type = "password" que oculta el input

 Se pueden usar los atributos maxlenght="12" para límite de caracteres, required para que no pueda quedarse vacío al enviar con un botón de tipo submit

El type = "date" crea un calendario


El type = "email" que hace que @ sea necesario en el campo input


El type = "tel" para agregar telefonos


El type = "number" para números

 Se pueden usar los atributos para limitar la cantidad con min="0" y max=10". y value="5" para poner una cantidad prederterminada

Usando type = "reset" que MUESTRA UN BOTÓN que elimina el contenido de todo el contenido de todos los inputs del formulario al que pertenece


Usando type = "radio" que crean "círculos" para selecinar

También podemos aplicar lo aprendido anteriormente usando for y type con un label para enviar información dentro de una solicitud.   
		< label for = "tituloo">Ingrese su educación: < / label >
	
		< label for = "Primaria"> Primaria < / label>
	
		< input type = "radio"     id = "Primaria"     name = "titulo"   value = "Primaria">
	
Note que se usa la combinación de for para label e id para input. Y muy importante value = "Primaria" o asignar el valor que tenga, porque este será el valor que se enviará en el URL. El atributo name = "titulo" en cada input 
	para indicar que este pertenece a la misma clase que el label principal

OBS: Si no se incluye el atributo name no se enviará el contenido de ese input.
