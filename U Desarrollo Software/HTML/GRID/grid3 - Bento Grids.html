BENTO GRIDS

¿Qué sucede si no sabemos con exactitud cuantos datos van a haber dentro de un contenedor pero debemos de acomodarlos bien para el usuario? Por ejemplo, si recibimos información de una base de datos no sabemos con certeza cuantos son y la cantidad puede variar cada vez.

Para ello se usará la propiedad grid-template-areas: y también es necesario darle un identificador (nombre) a cada uno de los elementos a los que vamos a desplegar en pantalla. 

< div class = "grid-container">
	< div class = "item" style = "grid-area: box-1"> 1 < /div>
	< div class = "item" style = "grid-area: box-2"> 2 < /div>
	< div class = "item" style = "grid-area: box-3"> 3 < /div>
	< div class = "item" style = "grid-area: box-4"> 4 < /div>
	< div class = "item" style = "grid-area: box-5"> 5 < /div>
< /div>

Por ejemplo, podemos hacer lo siguiente:

.grid-container1{
	border: solid 2px #f5b638;
	display: grid;
	
	grid-template-columns: 100px 100px 100px 100px;
	grid-auto-rows: 50px;
	
	grid-template-areas:
	"box-1 box-2 box-2 box-3"
	"box-1 box-4 box-5 box-5";
	gap: 0.1em;
}
