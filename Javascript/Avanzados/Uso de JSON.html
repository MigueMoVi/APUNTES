Uso de JSON

El objeto de espacio de nombres JSON contiene métodos estáticos para analizar valores y convertir valores a Notación de Objeto JavaScript (JSON).
No se puede usar un constructor para usar la librería JSON (new). Todas las propiedades de JSON son estáticas (como el objeto Math)
- Sirve para intercambiar datos entre un servidor y la aplicación.
- Archivos JSON: { key: value } OR [value1, value2, value3, ...]

Métodos

Este objeto tiene los siguientes métodos:

isRawJSON()

The JSON.isRawJSON() static method tests whether a value is an object returned by JSON.rawJSON().
Sintaxis

JSON.isRawJSON(value)

Return value: true if value is created by JSON.rawJSON(); otherwise, false

stringify()

Convierte un objeto de JS a un string JSON 

JSON.stringify( [OBJECTO] )

Por ejemplo: 

	const names = ["Spongebob", "Patrick", "Sandy", "Squidward"];
	const person = {
		"name": "Spongebob",
		"age": 30,
		"isEmployed": true,
		"hobbies": ["Jellyfishing", "Karate"]
	}
	
	const PersonString = JSON.stringify(person);
	const NamesString = JSON.stringify(names);
	
	console.log(PersonString);
	console.log(NamesString); 
	>> '{"name":"Spongebob","age":30,"isEmployed":true,"hobbies":["Jellyfishing","Karate"]}' 
	>> '["Spongebob","Patrick","Sandy","Squidward"]'

parse()

Convierte un string JSON en un objeto de JS

JSON.parse( [STRING] )

Por ejemplo: 

	const names = `["Spongebob", "Patrick", "Sandy", "Squidward"]`;
	const person = `{"name": "Spongebob","age": 30,"isEmployed": true,"hobbies": ["Jellyfishing", "Karate"]}`
	
	const PersonData = JSON.parse(names);
	const NamesData = JSON.parse(person);
	
	console.log(PersonData);
	console.log(NamesData); 
	>> Array(4) [ "Spongebob", "Patrick", "Sandy", "Squidward" ]
	>> Object { name: "Spongebob", age: 30, isEmployed: true, hobbies: (2) […] }

rawJSON()

El JSON.rawJSON()El método estático crea un objeto "JSON en bruto" que contiene un trozo de texto JSON. Cuando se serializa a JSON, el objeto JSON crudo se trata como si ya fuera un pedazo de JSON. Se requiere que este texto sea válido JSON. 

 JSON.rawJSON(string)
