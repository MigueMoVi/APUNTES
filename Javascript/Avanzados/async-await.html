Async/await

Async : Hace que una función retorne una Promesa
Await: ESPERA UNA PROMESA: Hace que una función asincrónica espere por una promesa

- Esto te permite escribir código asincrónico de una manera sincrónica
- Async y await SIEMPRE VAN JUNTOS - Async no tiene parámetros resolver o reject. "Es como una promesa vacía"
- Todo despues de Await se localiza en una cola de eventos

async function

La declaración async function crea un enlace de una nueva función asíncrona a un nombre dado. La palabra clave await está permitida dentro del cuerpo de la función, lo que permite escribir un comportamiento asíncrono basado en promesas de un estilo más limpio y evitar la necesidad de configurar explícitamente cadenas de promesas. 

function resolveAfter2Seconds() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve("resolved");
    }, 2000);
  });
}

async function asyncCall__() {
  console.log("llamando");
  const result = await resolveAfter2Seconds();
  console.log(result);
  // Salida esperada: "resolved"
}

asyncCall__();

Las funciones asíncronas siempre devuelven una promesa. Si el valor de retorno de una función asíncrona no es explícitamente una promesa, se envolverá implícitamente en una promesa.

async function foo() {
  return 1;
}

=

function foo() {
  return Promise.resolve(1);
}

async function expression

La palabra clave async function puede ser utilizada para definir funciones async dentro de expresiones y para crear funciones anónimas.

async function [nombre]([param1[, param2[, ..., paramN]]]) {
  enunciados
}

Note que no se ha declarado nombre de la función.

Ejemplos: 

function resuelve2SegundosDespues(x) {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve(x);
    }, 2000);
  });
}

const agregar = async function (x) {
  // Expresión de una función asíncrona asignada a una variable
  let a = await resuelve2SegundosDespues(20);
  let b = await resuelve2SegundosDespues(30);
  return x + a + b;
};
