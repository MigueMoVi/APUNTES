Práctica con fetch usando una URL

Usaremos la siguiente API para realizar esta práctica de GET y POST

https://reqres.in/api/users

No olvidar

Podemos guardar el resultado de un fetch en una variable en vez de solo llamarla. 

// Llamar a la promesa. Se mostrará en consola
fetch("https://reqres.in/api/users")
	.then(res => { console.log(res) } );

// Si queremos guardarla dentro de una variable y ver el resultado después
const promesa = fetch("https://reqres.in/api/users")
	.then(res => {return res} );
//Como es una promesa, debemos de usars [var].then(...)
promesa.then(datos => {console.log(datos)});

Como vemos recibimos un objeto de la respuesta de la API, por ello debemos de convertirlo a un objeto diferente para poder extraer la información 

fetch("https://reqres.in/api/users")
	.then( res => res.json() )
	.then( data => console.log(data) );

Y obtenemos un array: 

Object { page: 1, per_page: 6, total: 12, total_pages: 2, data: (6) […], support: {…}, _meta: {…} }

Podemos manejar los errores de la siguiente manera: 

fetch("https://reqres.in/api/users")
	.then( res => {
		if (res.ok){
			console.log("Éxito")
		}
		else{
			console.log("Error")
		}
	} )
	.then( data => console.log(data) )
	.catch( error => console.log("NO existe el usuario") );

Asi, podemos obtener dos respuestas

GET

Lo que acabamos de hacer es un GET. Recordemos que fetch hace un GET por defecto

fetch(
	"https://reqres.in/api/users",
	{ method : 'GET' }	
)
	.then( res => {...} )
	.then( data => ... )
	.catch( error => ... );

El código anterior se ve de la siguiente manera

fetch(
	"https://reqres.in/api/users",
	{ method : 'GET' }
)
	.then( res => {
		if (res.ok){
			console.log("Éxito")
		}
		else{
			console.log("Error")
		}
	} )
	.then( data => console.log(data) )
	.catch( error => console.log("NO existe el usuario") );
 // Obtenemos el mismo resultado visto anteriormente

POST

Cuando hacemos un POST tenemos que pasar los datos que vamos a enviar a la API especificamdp que estamos haciendo un post. 

fetch(
	"https://reqres.in/api/users",
	{
		method : 'POST',
		headers: {}              // Especificar que estamos pasando (Es un JSON?)
		body: JSON.stringify( { name: 'User 1', ... } ) // Contenido, datos en JSON
	}	
)
	.then( res => {
			return res.json()
	} )
	.then( data => console.log(data) )
	.catch( error => console.log("NO existe el usuario") );

Observe el siguiente ejemplo

fetch(

fetch(
	"https://reqres.in/api/users",

		method : 'POST',
		headers: { 'Content-Type': 'application/json' },

)
