Código síncrono

Se ejecuta línea por línea consecutivamente de una manera secuencial. El código espera una operación para y que las instrucciones que lo preceden, terminen, para que se pueda ejecutar

Código asíncrono

Permite realizar múltiples operaciones simultáneamente sin esperar
- No bloquea el flujo de ejecución y permite que el programa continúe
- (operaciones de E/S, peticiones de red, obtención de datos)
- Se maneja con: Callbacks, Promesas, Async/Await

Por ejemplo

// Código Fuente
console.log(1);
console.log(2);
console.log(3);
console.log(4);
	
// Resultado en Consola
1
2
3
4
	
// Código Fuente
console.log("Ejemplo 2");

setTimeout( () => console.log(1), 3000 );
console.log(2);
console.log(3);
console.log(4);
	
// Resultado en Consola
Ejemplo 2
2
3
4
1 (después de 3 segundos)
	
// Código Fuente
Mensaje_1(Mensaje_2);

function Mensaje_1(callback){
	setTimeout( () => {
			console.log(1);
			// Se ejecuta estrictamente después del 1
			callback(); 
		}, 2000 );
}

function Mensaje_2(){
	console.log(2);
	console.log(3);
	console.log(4);
}
	
// Resultado en Consola
...esperando 2 segundos...
1
2
3
4
