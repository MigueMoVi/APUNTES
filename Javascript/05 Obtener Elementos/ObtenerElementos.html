Obtener elementos del árbol DOM

Como sabemos, para usar Javascript tenemos que tener en cuenta que los elementos html de la página web se guardan el el árbol DOM, y por tanto tenemos que saber manejar esta estructura de datos con JS.

    innerHTML vs textContent

    ¿Cómo podemos manejar el contenido de estos elementos?

    para eliminar podemos usar una referencia al elemento:

    	const elemento = document.getElementById("nombre_elemento");

    Podrían ser varios... evaluar caso

    Para crear:

    	// Crear el elemento
	const nuevo = document.createElement('p')

	// Asignarle un id
	nuevo.id = 'nuevo_id'

	// Insertar elemento en html, hay que saber quien es su contenedor
	const contenedor = document.getElementById("nombre_contenedor");
	contenedor.appendChild(nuevo)

    Siempre se crea un elemento nuevo html y luego se le puede asignar una clase o id, para finalmente darle un texto.

    Para eliminar:

    	// Obtener referencia
	const elemento = document.getElementById("id_elemento")

	// Insertar elemento en html, hay que saber quien es su contenedor
	elemento.remove()

    >>> Intente eliminar y crear algún elemento del ejemplo

    Obtener elementos de cierta clase dentro de un contenedor

    Es recomendable usar lo siguiente

    .querySelector
    Devuelve un solo elemento. Una referencia a un solo objeto el primero con el que coincide y retorna un objeto que representa el elemento HTML específico (por ejemplo, HTMLParagraphElement
    .querySelectorAll
    devuelve una lista con todos los elementos que coinciden. Retorna un objeto de tipo NodeList (que actúa como una lista o array, pero sigue siendo un objeto). 
    	// Busca el elemento con id "contador" que esté DENTRO de la clase "aparte"
	const miContador = document.querySelector(".aparte #contador");

	console.log(miContador.innerHTML); // Resultado: " Contador "

    Observe que se usa el "." y "#" para especificar la búsqueda dentro de un objeto
