Constantes

Es una variable que no puede cambiar

OBS: No confundir con let que también sirve para asignar valores

Por ejemplo, usemos un input y un botón para calcular la longitud de una circunferencia:



El codigo es: 

	< label>El radio: 
	< input type = "text" id = "myText">
	< br>
	< button id = "mySubmit"> Calcular < /button>
	< br>
	< p id = "resultado" style = "margin-left: 60px;">< /p>

Y para JS

	const PI = 3.1416;
	let radio;
	let Long;
	
	document.getElementById("mySubmit").onclick = function(){
		// Obtener el valor
		radio = document.getElementById("myText").value;
		// Hacer casting
		radio = Number(radio);
		// Calcular y mostrar el valor
		Long = 2*PI*radio;
		document.getElementById("resultado").textContent = Long;
	}

Note que se usa constante a PI, esto significa que la variable PI no cambiará su valor jamás...
