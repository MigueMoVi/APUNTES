Casting - Type conversion

Changethe datatype of a value to another (strings, numbers, booleas)

Veamos el tipo de variable que hay de acuerdo a la alerta.

	let age = window.prompt("Ingrese su edad: ");
	age += 1;
	console.log(age);

Y obtenemos

	"[entrada]1"

Esto pasa porque se asume que se está recibiendo un string. El casting nos ayudará a manejar correctamente nuestros datos


Funciones de conversión

Vamos a usar las funciones para poder convertir el tipo de dato de una variable

	console.log("Conversiones parte 2");
	let x = "pizza";
	let y = "pizza";
	let z = "pizza";
	
	x = Number(x);
	y = String(y);
	z = Boolean(z);

Resultado

	NaN number
	pizza string
	true boolean

Ahora si cambiamos el valor de "pizza" de las 3 varaibles por "0" obtenemos: 

	0 number
	0 string
	true boolean
