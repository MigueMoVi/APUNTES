Curso de Javascript

Javascript es un lenguaje de programación interpretado que le da funcionalidades a los estilos y elementos de una página web

Tiene la extensión .js

Para enlazar nuestros archivos a la página principal debemos

  • CSS: En < header > colocar < link rel = "stylesheet" href = "ubicación_archivo/nombre.css" >
  • JS: En < body > colocar < script src = "ubicación_archivo/nombre.js" > < /script > 
 OBS:  La línea de < script...> < / script> debe estar dentro de body. Ver código de esta página.
		Se suele poner esta línea al final de body, ya que si existe una alerta u otras funciones que veremos más adelante, se ejecutarán antes que se cargue la página web

Además, si se trata de acceder a un elemento de la página HTML y este se encuentra líneas más abajo que < script > NO FUNCIONARÁ

Modificar el texto de la página web usando js

Las dos líneas que siguen están en blanco en el código HTML, pero son llenadas con código del script .js

		< div id = "strings">
			< p id = "string1">< /p>
			< p id = "string2">< /p>
		< /div> 
		document.getElementById("string1").textContent = "Primer string";
		document.getElementById("string2").textContent = "Luego sigue el segundo string";

Como se pudo ver primero se muestran los mensajes de alerta en pantalla y luego se escribió el texto. Cerrar la ventana y volverla a abrir para ver bien.
